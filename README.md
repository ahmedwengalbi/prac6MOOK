1. Адаптивная вёрстка — сайт подстраивается под размер экрана устройства.

2. Media queries — применяют CSS только при выполнении условия (ширина, ориентация и т.д.).

3. max-width vs min-width — max-width работает «сверху вниз» (от ПК к мобильным), min-width — «снизу вверх» (mobile-first).

4. Breakpoints — точки перелома, где меняется раскладка (576, 768, 992, 1200px).

5. meta viewport — сообщает браузеру реальную ширину устройства, без него media queries на мобильных не работают.

6. Grid — задаёт колонки через fr, легко менять их количество в media queries или через auto-fit + minmax().

7. Flexbox — для одномерных раскладок: header, footer, навигация, выравнивание.

8. Несколько media queries — да, можно и нужно; их комбинируют по условиям.

9. Без viewport meta — страница откроется в десктопном масштабе, будет сжата, текст мелкий.

10. Адаптивный vs отзывчивый — адаптивный использует фиксированные макеты под breakpoints, отзывчивый плавно тянется под любой размер.
